# Adestrador de Cães - Landing Page

Landing page moderna em React focada em SEO para adestrador profissional de cães.

## 🚀 Características

- **SEO Otimizado**: Meta tags, dados estruturados, sitemap.xml, robots.txt
- **Performance**: Lazy loading de imagens, code splitting, otimização de bundle
- **Design Moderno**: Tailwind CSS, design responsivo, animações suaves
- **Acessibilidade**: HTML semântico, ARIA labels, navegação por teclado
- **Conversão**: CTAs estratégicos, formulário de contato, WhatsApp

## 🛠️ Tecnologias

- React 18 com Vite
- Tailwind CSS 4
- react-helmet-async (SEO)
- framer-motion (animações)

## 📦 Instalação

```bash
npm install
```

## 🏃 Desenvolvimento

```bash
npm run dev
```

## 🏗️ Build para Produção

```bash
npm run build
```

O build otimizado será gerado na pasta `dist/`.

## 📱 Otimizações de SEO

### Meta Tags
- Title otimizado (até 60 caracteres)
- Description otimizada (150-160 caracteres)
- Keywords relevantes
- Open Graph para redes sociais
- Twitter Cards

### Dados Estruturados
- LocalBusiness Schema
- Service Schema
- Informações de contato estruturadas

### Performance
- Lazy loading de imagens
- Code splitting automático
- Otimização de fontes
- Compressão de assets

### Arquivos de SEO
- `/public/sitemap.xml` - Sitemap do site
- `/public/robots.txt` - Instruções para crawlers
